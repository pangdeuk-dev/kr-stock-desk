# KR Stock Desk

한국 국내 주식 보유 현황, 수익률, 투자일지, 매일 투자의견을 한 화면에서 보는 로컬 웹앱입니다.

## 이 앱이 하는 일

- 보유 종목을 직접 등록하고 네이버 모바일 시세로 주기 갱신 (장중 15초, 그 외 60초)
- 총자산·평가손익·월간 수익률(목표 +20%) 표시
- 평일 09:00 KST 시황 스냅샷, 11:00 KST 매수/매도/보유 실행 지시 (지정가·주 수·평단)
- 종목은 최대 6개. 없어도 되는 날에는 보유를 기본으로 함
- `briefings/YYYY-MM-DD.json` 이 있으면 채팅 에이전트 리서치를 우선하고, 주 수는 로컬 예수금으로 계산

## 이 앱이 하지 않는 일

- 실시간 호가(체결 단위) 보장 — 네이버 모바일 API라 수 초~수십 초 지연이 있습니다
- 월 +20% 수익 보장 — 목표 게이지일 뿐입니다
- 증권사 주문 실행 — 의견만 제시합니다

서버 프로세스가 꺼져 있으면 09:00/11:00 자동 생성은 건너뜁니다. 켜질 때 오늘 분이 없으면 따라잡습니다.

## 실행

```powershell
cd C:\Users\USER\projects\kr-stock-desk
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 http://127.0.0.1:8000 을 엽니다.

데이터는 `data/desk.db` (Git에 안 올라감)에 저장됩니다.
